## 目的与执行边界

本轮完成 UPDATE-181 建议的三档分辨率、center/offset 六份完整 Definition 静态矩阵。问题限定为：按每档分辨率为池体三个轴选择一个几何相位，使最近格点拟合后的池内粒子中心尽量向连续池盒内收；检查相位对池、液滴和固定边界的共同影响。选择规则和精确输入生成由 [`f4r_pointref_phase_matrix_v1.py`](../../../../scripts/f4r_pointref_phase_matrix_v1.py) 固定，输入文件及 SHA-256 见本目录与 [机器回执](receipt.json)。

使用 GenCase v5.4.354.01（SHA-256 `a1b6414e0f716669363d1a80a05e133085c04995e15716e3c1f0406e0d023226`），六个候选均以 `-threads:1 -save:all` 成功退出。原始 Definition 不变；每份候选只在全局 `<geometry><definition>` 新增一个 `<pointref>`。六个未修改基线的 GenCase `.bi4` 均与仓库已存档 `.bi4` **逐字节一致**，因此原矩阵人口重现不只是粒子数相同。基线和候选 fluid VTK 的坐标与 Mk 用于本轮边界/质心核对。

没有打开 production HDF5；没有运行 solver、worker、GPU 或队列任务；没有写 registry/ledger；T1/T2 均为 false，qualification credit 为 0。候选只用于前处理设计诊断，不是已冻结或获资格的 F4 数值方案。

## 结果解释与判定

1. **几何目标达成，但只是池体的静态端点目标。** 候选按分辨率变化相位，确实让池 MK1 粒子中心全部内收；这与 UPDATE-181 单池细档探针相符。它没有证明动态穿墙得到修复。
2. **全局相位同时改变液滴和壁面离散。** `<pointref>` 位于全局 definition。相对基线，池质心分别移动约 `(+0.007,−3.182,−3.171) mm`、`(+0.070,+1.256,+1.262) mm`、`(+0.047,−1.018,−1.065) mm`（粗/中/细）。液滴质心也发生分辨率相关移动；粗档 offset 的 x 移动约 `+4.125 mm`，粗档两液滴 z 均移动约 `−3.182 mm`。因此它不是“只修池边界”的独立干预。
3. **离散总质量更接近连续目标，但质量分母仍随相位改变。** 不做质量缩放时，以 PLAN 记录的连续总质量 `52.416 kg` 为参照，六例的总流体质量误差绝对值都下降：粗档 center/offset 从 `+10.087%/+10.087%` 到 `+8.338%/+8.714%`；中档从 `+10.845%/+11.199%` 到 `+3.713%/+4.064%`；细档从 `+5.923%/+5.646%` 到 `+5.112%/+5.389%`。跨分辨率质量 spread 也从 center/offset/合并的 `4.441%/4.994%/4.994%` 变为 `4.269%/4.277%/4.601%`。这是值得保留的静态正向信号，但中档质量仍下降约 6.4%，且这是全局相位重新离散池和液滴后的结果；不能解释成质量守恒、纯池体效应或数值资格通过。细档 center/offset 液滴人口差还从基线的 `center +672` 翻成候选的 `offset +672`，表明候选相位正在重新塑造背景差异。
4. **候选暂不进入求解器。** 它改变整个 fluid 初态和固定边界人口，因而无法单独检验原 F4R 初态池边缘/穿墙因果；也未达到跨分辨率质量定义。不能将池体包络内收作为足够验收条件，也不应质量缩放抵消变化。
