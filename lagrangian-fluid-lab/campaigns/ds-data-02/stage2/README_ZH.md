# DS-DATA-02 第二阶段工作入口

目标是从已有336例视觉数据形成有范围限定的科学证据、标签和可重放内部数据产品。七族各48例的历史成果保持。`review-source/` 是云端审阅方案的原样副本，角色为建议与证据；实际运行、资源与验收以本地收据为准。

实现基于审阅集成版本 c30f8348d66debc83c581fed964aa3a2868dc2f2，工作分支 codex/ds-data-02-stage2。新入口 `ds_data02_stage2_dispatch.py` 复用不可变runtime v2与strict v1，增加有限数值检查及父进程取消。batch日志直接落盘，读取独立终态收据，失败停本批次尚未启动的同构请求；不同家族分别提交批次。

恢复顺序：检查真实共享ledger及在运行进程；检查已有execution-receipt；完成CURRENT336的精确数据绑定；逐族执行有预算的科学字段扫描；F2/F4/F6原生缺失取证与其他族参考准备并行；随后按任务验收、生成标签与产品。不得因为会话恢复重启仍存活的任务，也不覆盖已完成attempt。

测试只证明入口行为，不给予QI/QN/QE信用。科学数组必须经实际读取和原生对账；两个哨点通过不自动覆盖整个家族。
