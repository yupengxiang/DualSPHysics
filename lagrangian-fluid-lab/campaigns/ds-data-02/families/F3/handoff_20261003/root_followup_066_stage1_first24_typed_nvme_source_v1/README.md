# F3 fresh066 typed NVMe source handoff

This package binds five completed native full836 receipts to the reviewed strict
NVMe converter: AY0270, AY0290, AY0300, AY0340, and the existing AY0640
first8 case. Each owner records the actual native output root and data root,
prepared report, static XML and BI4 references, genuine GenCase receipt,
parent initial QA, source owner, Root123 authority, and the exact native
condition identity.

The fresh066 requests use the mature ds_data02_nvme_convert_v1.py command
contract with a 24 GiB staging cap and 100 GiB worker floor. They are CPU
conversion requests, but every request is disabled: no launch, execution,
production approval, Q-N grant, precision claim, or independent case increment
is present. Typed receipt, conversion report, H5, PartVTK, and visual decision
hashes remain null until Root authorizes and runs the strict worker.

AY0640 keeps the completed receipt's original physical ID and first8 native
scope. It is carried as existing evidence; it is not relabeled as a new
first24 physical condition. The unfinished AY0360/0370/0410/0430/0440/0480/
0520/0540 cases are excluded.

The generator and contract test use JSON, XML, Python, and executable metadata
only. They refuse to hash BI4, CSV, H5, HDF5, NPY, or NPZ payloads and do not
start a solver, converter, or audit. Run:

python3 -B tests/test_fresh066_contract.py
