# fresh191: F5 M110/T100 terminal metadata preflight

This F3-scoped package records the terminal producer chain for
`F5_COMPACT_RUNUP_RECOVERY_C082S1_M110_T100` after original1189 completed with
return code 0 and atomically published its full 801-frame render. It is an
assigned-F3 metadata handoff for an actual F5 case; it does not change the F5
case family or grant case credit.

The package binds GenCase, initial QA, native, typed conversion, XMF, bed, and
render receipts to the same case and physical identity. It records the actual
time endpoint `16.00008511666941 s`, 801 frames, 194427 particles, N3 output,
the parent QI1434 evidence, and the render publish receipt. Native canonical,
typed legacy, XMF physical/SourceDef, source-plan JSON, and the prospective
canonical value are preserved as separate roles. The initial placement
precision negative remains explicit; this package grants no numerical,
containment, sub-DP, Q-N, or Q-E claim.

The source agent read only metadata JSON/XML/XMF and stat'ed the published PNG
paths. It did not open or hash H5, BI4, IBI4, CSV, DAT, or VTK payloads, and it
did not open or hash PNGs. Personal visual review of all 34 contact sheets and
the nine navigation frames is deferred to fresh192.

Run the read-only validator from this directory:

```sh
python3 -B scripts/validate_fresh191.py
```

The builder is retained for provenance and is not a job launcher:

```sh
python3 -B scripts/build_fresh191.py
```

The builder should only be rerun against the same immutable producer metadata
before adoption; it must not be used to overwrite a consumed package.
