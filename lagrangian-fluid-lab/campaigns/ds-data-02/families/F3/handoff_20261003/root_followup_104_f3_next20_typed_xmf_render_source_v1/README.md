# F3 fresh104 Root839 next20 downstream source handoff

This F3-local source package prepares one disabled native-to-typed conversion,
one disabled N3 XMF export, and one disabled Root023 render successor for each
of the 20 registered Root839 native cases. It binds each case to its own Root839
attempt, Root704 prepared-input report, physical condition, and forcing producer
metadata. No native receipt, H5, XMF, render receipt, or future artifact hash is
claimed here; every downstream request remains disabled until its own upstream
producer is completed/0 and Root revalidates the metadata closure.

The converter owner adapter embeds the exact Root839 `physical_binding` and the
canonical `ds-data-02.physical-binding.v1` hash, while retaining the old
`root_followup_065` owner/condition template as a separate source namespace.
The pure JSON canonical check is performed by `validation/validate_fresh104.py`;
actual conversion must repeat the converter's own scope check before launch.

The package copies only JSON/Python/XML-adjacent metadata and source code. It does
not open, copy, or hash BI4, CSV, DAT, VTK, H5, or solver science payloads. Raw
payload digests appearing under `metadata/upstream/root839/native-input-attestations.json`
are copied producer attestations from Root839 request JSON and are not recomputed
by this package. No job, solver, converter, renderer, ledger, or shared registry
was started or modified. Independent-case increment remains zero; numerical
precision, Q-N, and production approval remain closed.

Validation: `python3 validation/validate_fresh104.py`.
