# F2 first24 delegated visual decisions: RX055 and RX060

This source-only package records the first two F2 original first24 cases that were absent from `ROOT_LIVE_RESUMPTION_CHECKPOINT_113.json`: RX055 and RX060. Each case has actual GenCase, initial QA, native, typed, XMF, and Root023 render metadata references, plus SHA-256 values for all 17 contact sheets and key frames 0, 65, 115, and 400.

The reviewer personally viewed every listed PNG. The decisions are visual-only: numerical precision remains unaccepted, Q-N is not granted, and no production or qualification claim is made. Late identity exclusions are retained as reported by the producer; no particles are filled or reclassified. The source-plan physical hash and the actual converter legacy-owner hash remain separate because the source owner has no `physical_binding`.

The package only writes JSON/Python metadata in the F3 worktree. It does not read, hash, copy, or decode BI4, H5, CSV, DAT, VTK, or other scientific payloads, and it starts no jobs or shared-state updates.
