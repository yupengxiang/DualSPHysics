# F4 fresh095 pre-solver GenCase basic initial QA

Fresh095 breaks the pre-solver gate out of the native-solver chain. It binds
all 24 individual Root44424/Root445 GenCase completed/0 receipts recorded in
the adopted fresh092 actual binding, together with each prepared XML,
Definition, prepared-input report, and producer-attested GenCase BI4.

The package contains one disabled Root-owned CPU audit request per case. The
worker reads the GenCase BI4 only inside that future registered CPU job through
the registered safe BI4/PartVTK reader. It checks actual Posd/Idp structure,
true 3-D, finite positions, complete unique initial UIDs, XML fixed/fluid/source
UID partition, inclusive XML drawbox extrema, drop/pool separation, tank
containment, and source/recipe invariants. XML fixed/fluid blocks and UID
ranges provide the type/source partition; raw Mk/Type arrays are not claimed
as observed.

The source package never opens or hashes BI4/H5/VTK/CSV payloads. The GenCase
BI4 producer SHA remains an attestation and is deferred as a request input
with a null source-side hash. The future worker verifies it when Root runs the
CPU audit. Initial velocities are reported from the generated XML declaration
only. Native frame-0 velocity is deferred to fresh094 after a full native
solver run.

Native mass and nominal continuum mass are reported separately and never gate
this stage. Exact continuum lattice/center, precision, Q-N, visual, solver,
and production approval remain outside the package. Root470's strict failed
diagnostic is preserved and is not promoted.

All 24 requests are source_only_disabled, launch_allowed=false,
launch_owner=root, and have no native receipt/frame-0 dependency. Root may
derive the next full-native request only from an actual fresh095 pass; fresh093
and fresh094 source bytes are unchanged.

Validate the static package with:

PYTHONPYCACHEPREFIX=/tmp/ds02-fresh095-validator-pyc python3 tests/validate_source_contract.py

The validator is source-only and does not open or hash scientific payloads.

The retained post-native package is the isolated
root_followup_094_stage1_f4_basic_native_input_qa_v1 handoff.
