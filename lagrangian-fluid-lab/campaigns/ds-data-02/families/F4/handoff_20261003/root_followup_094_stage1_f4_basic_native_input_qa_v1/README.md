# F4 fresh094 stage-1 native input QA

Fresh094 is a separate Root-owned CPU audit for the 24 F4 native cases. It
consumes one completed Root230 native receipt and one producer-attested
solver-saved `Part_0000.bi4` per disabled request. The worker checks measured
3-D finite positions, complete unique `Idp`, exact actual counts, XML-derived
source UID blocks, inclusive source drawbox extrema, drop/pool separation, the
native gap inside the tank, and source XML/Definition invariants.

The worker reports native mass beside nominal continuum mass without rescaling.
Exact continuum center/lattice checks and the Root470 centered-reference
result remain diagnostics; they cannot be used as a precision, Q-N, visual or
production claim. Saved frame-0 velocity is a separate downstream audit.

The source package reads only JSON/XML/Python metadata and producer SHA
attestations. BI4/Posd/Idp are opened only if Root enables the disabled CPU
request with actual receipt/frame path/SHA. No solver, conversion, rendering,
array copy, shared registry write or case credit is produced here.
