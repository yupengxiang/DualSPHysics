# F4 fresh064 full native 1201-frame NVMe typed conversion

This source-only package registers two disabled CPU conversion requests for
the completed F4 gap 0.18 and gap 0.26 native077 attempts. Canonical physical
owners use fresh062 metadata IDs and hashes:
F4_DROP_B08_gap0p18000_xoff0p00000_yoff0p00000_uz0p50000 and
F4_DROP_B08_gap0p26000_xoff0p00000_yoff0p00000_uz0p50000.

The 077 runner request case/condition fields remain historical source-plan
aliases in semantic-binding.json and are not copied into canonical owners.
Owners reuse the mother real full1201 owner schema. Each request binds actual
077 completed/0 native output, exact 076 prepared XML/BI4/receipt, and passing
069 initial QA. It calls unchanged ds_data02_nvme_convert_v1.py and unchanged
ds_data02_direct_convert.py. All 1201 native frames are streamed, with
official PartVTK checks at frame 0, midpoint, and final frame. NVMe staging is
capped at 24 GiB and the wrapper enforces a 100 GiB free-space floor.

Requests are launch=false and launch_allowed=false for Root review. This
package did not launch conversion, read native arrays, decode BI4/H5, read CSV
arrays, or write shared registry/ledger state. It makes no Q-N, precision,
visual, or production claim.
