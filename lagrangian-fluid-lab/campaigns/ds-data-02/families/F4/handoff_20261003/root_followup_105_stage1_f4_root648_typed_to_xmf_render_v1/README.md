# F4 fresh105 Root648 typed to N3 XMF to Root023 source handoff

Fresh105 is a disabled successor after Root647 proved the concrete Root645
failure: the NVMe wrapper received ds_data02_direct_convert.py as a positional
token after the separator. The unchanged wrapper passes its remainder to the
direct converter parser, so Root645 returned code 2 before conversion. Root647
and fresh104 bytes remain immutable.

There are 24 typed, 24 N3 XMF, and 24 Root023 render successor requests. Each
is disabled and leaves future receipt, conversion, XMF, render, H5, and image
hashes null. A typed case may be enabled only after its own Root648 corrected
request has a completed/0 receipt and a passing 1201-frame N3/PartVTK report.
XMF and Root023 remain downstream derived views.

The Root638 renderer contract carries explicit LP/VTK/BLAS/OMP environment
limits of two, a conservative 24-thread CPU reservation, 14400 seconds, and
global render concurrency two. Source-owner, source-plan, and derived legacy
converter scopes remain separate.

The argv checker parses the wrapper and direct argparse source and checks all
24 corrected commands. The Root648 poller reads only JSON receipts/reports and
never opens H5 or solver arrays. This package does not launch a job, read or
hash BI4/H5/VTK/CSV/DAT/scientific arrays, or write shared state.
