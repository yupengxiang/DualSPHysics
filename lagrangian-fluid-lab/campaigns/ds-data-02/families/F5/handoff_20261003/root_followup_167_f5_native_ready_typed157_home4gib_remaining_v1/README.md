# F5 fresh167

This source-only package binds five real NEXT34 F5 full801 native producers to disabled typed157 Home/NVMe successor requests.

Selected conditions: M106_T085, M106_T095, M108_T085, M108_T095, M110_T085. Each has actual GenCase completed/0, actual initial placement/Mk50 QA basic pass excluding the retained exact-DP precision negative, and actual native full801 completed/0 with 194427 particles (158559 fixed, 4210 moving, 31658 fluid, 0 floating), 3D.

The package fixes the fresh165 runtime closure defect: `input_files` contains regular files only. Producer directories are listed under `scientific_data_root`, `source_provenance.producer_directories`, and `directory_provenance`; they have no directory hash and are never walked. Opaque BI4/DAT/CSV/binary hashes are producer attestations. JSON/XML/Python metadata and source files are checked at their current bytes.

Every request is disabled (`launch=false`, `execution_allowed=false`, `conversion_allowed=false`, `solver_allowed=false`) and uses Root142 CPU2, serialized conversion, 24 GiB private NVMe staging, 100 GiB NVMe reserve, 4 GiB Home publish cap, 500 GiB Home floor, and 2 GiB publish headroom. Typed/H5/XMF/bed/render hashes remain null. Canonical physical condition, source definition/plan, and prospective legacy-owner scope v0 is computed from owner metadata only and remains separate from any future typed producer legacy report/hash.

No science payload was read, copied, or hashed by source preparation. No job, solver, converter, ledger, registry, or shared integration state was changed.
