# F5 fresh082: explicit analytic thick-bed fallback

This package is a source-only fallback for the F5 3-D runup case. It preserves the existing piston/wavemaker motion, fluid box, 16 s/.02 s solver recipe, and diagnostic penetration bins. It changes the bed representation to one closed "drawextrude closed=true" profile volume with y extent [-0.22, 0.22] m, top profile nodes [[-0.2, 0.0], [2.0, 0.0], [3.0, 0.28], [3.6, 0.448], [3.9, 0.448], [4.4, 0.05], [4.8, 0.05]], and a 0.20 m vertical extrusion below the top profile. The source bed marker remains mkbound=40; Root must verify the generated native marker mapping (Mk50) from the fresh receipt/XML.

The official DualSPHysics examples cited in official-evidence.json establish the XML mechanism. This is a source syntax and geometry contract, not evidence that C082 has been generated or solved. The source does not call drawfilestl or autofill; it does not rely on a post-draw erase/clip selector to create the bed volume. The design basis is h=1.0*sqrt(3)*dp=0.034641 m; the 0.20 m vertical thickness and 0.08 m bed margin beyond the fluid y half-width each exceed 2h=0.069282 m. Root must still measure actual coverage, overlap, mass, and dynamics.

A061 and B071 remain independent actual negative dynamic audits. A061 ended with severe below-bed penetration at 0.5 and 1.0 s. B071 Root201 completed all 51 frame reads with no UID loss/nonfinite rows but still had 15,793 fluid rows below 1 DP at frame 50, deepest depth 0.558292 m, min z -0.1344195 m. Those results reject both prior conditions and are preserved here; they do not identify C082 as successful.

The package contains disabled requests for genuine GenCase, structural native QA, frame-zero Type0/native-Mk50 coverage, a 1.0 s/51-frame native qualification, NVME typed conversion, XMF, and a dynamic bed audit. Every request has execution_allowed=false, launch_allowed=false, and full801_authorized=false. Root must bind actual producer receipts and counts after each stage and manually review every saved state. The dynamic worker reports finite Type-3 fluid rows only inside C082's exact profile x domain and y footprint, retaining all initial fluid UIDs as the denominator and reporting 1 DP/2 DP counts, fractions, depths, nonfinite rows, and unexplained UID loss.

C082 is a bounded fallback after the two failed same-class A/B repairs. It does not authorize another autofill repair loop, change a penetration threshold, increase case count, or grant Q-N/full16/full801.
