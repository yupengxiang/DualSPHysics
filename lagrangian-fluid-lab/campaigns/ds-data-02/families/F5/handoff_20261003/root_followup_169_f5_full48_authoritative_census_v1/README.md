# F5 fresh169 authoritative full48 census and Root993 bed handoff

This package is metadata/source-only. It records the current 48-row C082S1 physical-condition census as two A endpoints, twelve 16 s Mother conditions with actual full801 native receipts, and all 34 current NEXT34 source conditions. It deduplicates by `physical_case_id`.

The 11 NEXT34 rows without a selected completed native receipt are listed as `native_pending_next34`; their GenCase and initial-placement receipts are retained and no replacement cases or counts are invented. Four Mother T120 rows and the six fresh110 parent conditions remain disabled provenance outside this 16 s census. Historical A/B penetration and exact-DP lattice negatives remain preserved.

Root993 status is bound in `metadata/root993-bed-status.json`: M086_T095 and M088_T085 now have real XMF receipts in their `xmf/manifest.json`; M088_T095 remains WAIT under the preserved Root998 controller path. All three bed requests are disabled. The binding uses original138 numeric logic through the fresh161-style in-memory CASE_ID adapter; source MkBound40 to native Mk50 is explicit.

Canonical physical condition, source-plan/definition, typed legacy scope, and XMF producer metadata are separate provenance roles. This package makes no cross-resolution hash claim, grants no Q-N or case credit, and reads or hashes no BI4/H5/CSV/DAT/VTK science payload.

Run the read-only contract check from this directory:

```text
python3 scripts/validate_fresh169.py
```

The validator report is intentionally excluded from `manifest.json` to avoid self-referential hashes; it is regenerated by the command above.
