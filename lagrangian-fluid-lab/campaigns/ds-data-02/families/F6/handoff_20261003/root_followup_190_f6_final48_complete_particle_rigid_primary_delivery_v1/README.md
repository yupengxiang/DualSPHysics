# F6 fresh190 final48 primary delivery

This package is a metadata-only primary delivery index for the complete F6 final 48 visual cases at frozen checkpoint 262. It freezes the source membership chain `frozen8 ⊂ actual24 ⊂ final48`, joins each physical case to its own native, typed, XMF/XML, renderer, published-PNG metadata and full-time rigid-motion evidence, and keeps the old baseline/Part and scope absences explicit.

The authoritative inputs are the frozen `ROOT_LIVE_RESUMPTION_CHECKPOINT_262.json`, Root1345 current full336 index, Root1276/1313 actual first24 products, Root1321 particle/rigid delivery, Root1305 full-time rigid product, and Root1341/1345 final DZXY S1375/YAWP18 evidence. The last case uses Root1345's checkpoint-262 decision plus fresh189's personal review and Root1341 QI; the old Root1321 one-pending status remains only as a preserved predecessor reference.

`metadata/final48-delivery.json` contains 48 ordered rows. Each row preserves native canonical, actual converter/typed legacy, XMF/source-plan, accepted semantic, and source-definition roles separately. Rigid products retain 241 rows, finite required fields, and the producer's native-time tolerance of `1e-6`; the package does not newly certify the historical baseline Part column or a full CSV time-vector match.

PNG entries are published visualization references. This package only records their producer metadata and filesystem statistics; it does not reopen or hash PNGs, and it does not read or hash H5, BI4, CSV, DAT, or VTK scientific payloads. No solver, conversion, renderer, registry, ledger, or case-credit action is performed here. Numeric precision, Q-N, Q-E, strict containment, all-UID survival, and mass equality remain unclaimed. Physical mass `128 kg` and native support mass `256 kg` remain separate. The final DZXY S1375/YAWP18 omissions remain `3` terminal fluid particles, first missing frame `7`, `234` affected frames, and `700` particle-frame omissions with unknown cause/location/state.

Run the read-only validator with:

```text
python3 scripts/validate_final48.py
```
