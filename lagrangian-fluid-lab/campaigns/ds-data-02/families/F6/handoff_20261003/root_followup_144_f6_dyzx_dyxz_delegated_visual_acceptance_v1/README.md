# fresh144: F6 delegated visual evidence for two actual Root951 cases

This F6-only package records my delegated visual review of the two actual
Root951 physical cases selected by receipt and `physical_case_id`:

- `F6_STAGE1_ANGULAR_RELEASE_DYZX_S0875_YAWP06_DP025`
- `F6_STAGE1_ANGULAR_RELEASE_DYXZ_S1625_YAWM18_DP025`

For each case I personally viewed all 11 chronological contact sheets and the
nine key frames at indices `0, 24, 48, 72, 96, 120, 168, 192, 240`. The
selected Root951 receipts are terminal `completed` with return code `0`, and
the package binds the same-case GenCase, initial-native QA, full native,
FloatingInfo state-zero omega audit, typed conversion, H5 audit, N3 XMF, and
full 241-frame render/publish metadata.

The review records what is visible in the rendered artifacts: release and
impact evolution, body attitude, wave development and decay, camera coverage,
and failure-screen observations. It keeps producer lifecycle omissions and
unknown final UID interpretation from the actual typed report. It does not
infer angular velocity from particle V0; it uses each case's own state-zero
FloatingInfo report. It does not assert precision, Q-N/Q-I, production
approval, or global case credit.

Source-plan, source-canonical, classified converter, and actual typed producer
condition scopes are retained as separate roles. The package hashes only JSON,
XML, and PNG visual artifacts. It does not open or hash BI4, H5, CSV, DAT, or
VTK scientific payloads, and it starts no jobs or writes shared state.
