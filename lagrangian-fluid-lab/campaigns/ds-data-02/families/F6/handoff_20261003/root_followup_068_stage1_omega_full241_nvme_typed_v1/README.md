# F6 fresh068: full241 typed NVMe conversion source package

This isolated F6 package prepares two disabled, Root-owned CPU conversion requests for the completed native098 endpoint outputs. It binds each request to the Root073 canonical physical owner, the actual GenCase073 receipt, the actual native098 completed/0 receipt, the actual QA090 terminal pass, and the actual FloatingInfo102 state0 corroboration.

The unchanged `ds_data02_nvme_convert_v1.py` wrapper is the only execution entry point. Root may enable a request after review. This package does not launch a solver, decode BI4, open H5, read CSV arrays, run PartVTK, or write a shared registry/ledger. It records the exact command and input hashes for Root execution.

Both requests require all 241 native states from `Part_0000.bi4` through `Part_0240.bi4`, with official PartVTK checks at frames 0, 120, and 240. No solver option, time option, forcing, DBC, or mdbc value is introduced by conversion. The NVMe contract is a private `/tmp/ds02-nvme-conversion` stage with a 100 GiB free-space floor and a registered 24 GiB peak limit.

The generated XML typed identity is retained: fixed type 0/mk 30 (`73441`), floating type 2/mk 60/body ID `mk:60` (`16384`, Idp `73441..89824`), and fluid type 3/mk 1 (`327680`, Idp `89825..417504`). Physical body mass `128 kg`, native lattice support `256 kg`, and solver interaction `masspart 0.015625 kg` remain distinct, with no normalization or rescaling.

Root073 physical condition hashes and source-plan condition hashes remain separate. The FloatingInfo102 summary records low observed omega `[0.02, 0.029999999, 0.015]` and high observed omega `[0.16, 0.23999999, 0.12]`; particle V0=0 is never interpreted as proof of zero angular velocity. Q-N, precision, visual, and production claims remain ungranted.

Files:

- `owners/`: additive typed owners with the unchanged Root073 `physical_binding`.
- `requests/`: exact disabled executable commands for Root's unchanged NVMe wrapper.
- `helper-binding.json`, `conversion-contract.json`, `semantic-binding.json`, `source-input-binding.json`: bounded source contracts and provenance.
- `tests/test_fresh068_contract.py`: static metadata/hash checks; it does not execute conversion or inspect arrays.
