# F6 fresh140 — F2 actual Root812 → typed157 disabled handoff

This package is a bounded, disabled CPU conversion handoff for **12 of the 20**
unaccepted F2 cases whose Root812 full401 native receipts are already
`completed`/returncode `0`. The other eight unaccepted cases remain in
`metadata/selection-frozen.json`; Root995's RX049/ROT075 retry is explicitly
excluded and is not duplicated.

The owner shape follows the Root816 F2 owner builder. The physical/source-plan
hash is retained as provenance, the prospective legacy owner scope is recorded
separately, and both the canonical physical binding hash and actual converter
scope stay null until the real typed producer establishes them. The 3-D,
401-frame, 4 s recipe and measured GenCase/initial-QA/native counts are bound
from existing JSON/XML producer metadata. No mass, precision, Q-N, production,
or case credit is asserted.

Every request is `ds02.runner-request.v2`, `kind=cpu`, `cpu_task_kind=conversion`,
`cpu_threads=2`, estimated/publish Home cap 4 GiB, NVMe staging 24 GiB, NVMe
free reserve 100 GiB, and disabled (`launch=false`, `execution_allowed=false`).
The command is the Root974 Home-capped converter contract with the verified
PartVTK/decoder attestations. Root142 runtime/strict/policy064 and the frozen
resource window are recorded in the package metadata.

The source agent read only bounded JSON/XML/source metadata. It did not open,
copy, or hash BI4/H5/CSV/DAT/VTK/Run.out or native data. Scientific paths occur
only in `future_input_files` with null SHA and producer-only labels. Root must
perform any live Root142 reservation and actual conversion; no request is
enabled by this commit.
