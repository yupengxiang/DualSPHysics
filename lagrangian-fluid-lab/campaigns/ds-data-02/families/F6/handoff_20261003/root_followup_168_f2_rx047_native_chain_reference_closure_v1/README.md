# fresh168: RX047 native-chain reference closure

This F6-scoped handoff closes the three historical F2 RX047 references that
fresh167 intentionally left unresolved in the role-aware registration index:

- `ROT075`
- `ROT090`
- `ROT105`

The closure follows each immutable delegated decision to its sibling visual
review and chain-closure JSON, the Root951 render request and wrapper, the
actual Root812 native request/receipt, and the typed conversion report's
`source_provenance.solver_receipt`. The native receipt and solver-receipt
metadata agree on case identity, physical identity, terminal status, and
return code. The Root1205 rows remain unchanged and continue to report a
historical native scope of `null`; fresh168 records the resolved direct role
separately instead of backfilling that old index.

For `ROT075` and `ROT105`, the native request and receipt are present in the
accepted decision's chain closure. For `ROT090`, the aggregate chain audit
contains the accepted case but does not repeat its producer chain; the receipt
comes from the accepted decision and the matching request is resolved from the
immutable Root812 native-enablement roster. That distinction is recorded
explicitly in the metadata and is not treated as a new native run.

The package records semantic, native-request, actual-converter, render,
source-plan, and source-definition scopes as separate roles. It makes no
equality claim between them. The F2H10V2 coarse mother remains an explicit
true absence: its native request has no physical-condition field and fresh168
does not substitute a top or canonical hash.

Only JSON/XML/Python metadata references were inspected. Scientific payload
references from render input lists are counted and omitted from this package;
no solver, converter, renderer, array read, payload hash, shared-state write,
or case credit was performed by fresh168.
