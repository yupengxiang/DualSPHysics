# F6 fresh066 initial-native QA contract fix

fresh064 was consumed by Root strict CPU as a disabled source package. It
failed before PartVTK or any native array read because its binding called the
historical evidence field `historical_evidence_preserved`, while the worker
required `historical_evidence`. fresh066 preserves 064 unchanged and corrects
that source/worker contract in a new scope.

The exact genuine GenCase 073 endpoint XML/BI4 pairs remain the only native
inputs:

- `F6_STAGE1_ANGULAR_RELEASE_OMEGA_S025_DP025`,
  `angularvelini=[0.02,0.03,0.015] rad/s`;
- `F6_STAGE1_ANGULAR_RELEASE_OMEGA_S200_DP025`,
  `angularvelini=[0.16,0.24,0.12] rad/s`.

`qa-binding.json` uses schema v2 and binds every source definition, canonical
physical owner, source plan/build receipt, generated XML/BI4, completed 073
receipt, historical QA019/semantic020 report, and prior typed QA script. It
keeps the source-plan condition hash separate from each canonical physical
condition hash. The worker now verifies the owner source-plan hash and source
path in addition to the 064 checks, and requires the corrected exact
`historical_evidence` list of two records.

The request is intentionally disabled because Root's QA086 execution receipt
records the 064 contract failure and its final native QA index was not
produced. Root must keep this request disabled until the QA086 receipt and
index gate is reviewed and the fresh066 request is explicitly enabled. This
package itself does not invoke PartVTK, read BI4/H5/CSV arrays, run GenCase or
the solver, or create numerical evidence.

When Root later enables the request, the worker invokes official PartVTK on
the two exact 073 pairs and writes fresh per-endpoint CSV/JSON output under a
new attempt root. It checks exact native counts
`73441/0/16384/327680/417505`, finite and positive native fields, complete UID
range, type/Mk partitions, true 3D, zero initial fluid and serialized GenCase
body velocities, coordinate uniqueness, gross-overlap exclusion, weighted
center, and the distinct mass semantics `256 kg` native support, `128 kg`
physical body mass, and `0.015625 kg` solver masspart.

Particle `V0=0` remains a GenCase serialization observation and does not prove
zero angular velocity. Full native FloatingInfo state-0 corroboration remains
a later Root-owned step. QA019 and semantic020 remain preserved and are never
rejudged here. The package carries no Q-N, precision, visual, or production
approval and increments the independent case count by zero.
