# F6 fresh131 delegated visual package

This package starts with an independent physical-visual sidecar for the
already-consumed fresh130 case. The fresh130 package remains immutable. The
sidecar records what is visible in the reviewed contact sheets and keyframes:
the initial body release, the early fluid impact/splash, and the later pose and
immersion change are qualitatively discernible. It does not turn those visual
observations into a numerical, precision, Q-N, UID, or production claim.

The producer lifecycle values are retained as metadata: 241 source/rendered
frames, zero reported active nonfinite states, 933 cumulative missing events,
234 nonzero-missing frames, and a maximum of four missing particles in one
frame. Missing-event counts are not interpreted as final UID loss.

The sidecar validator is metadata-only:

```text
python3 workers/validate_fresh131_sidecar.py
```
