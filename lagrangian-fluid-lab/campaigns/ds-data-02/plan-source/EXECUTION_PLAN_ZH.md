# DS-DATA-02：七族并行配方、范围与数据产品

## 唯一目标
构造七族典型三维拉格朗日流体数据集：真实可用轨迹、已验证的数值配方和参数范围、独立split、原生数值输运标签、无模型evaluator、可移动数据包。训练/推理/权重重放/调参/排行榜全部不属于本活动，预算均为0。
本计划不许以模型分数否决数据，不许以Q-E或独立材料示踪作为全部核心数据前置；也不许把5帧canary、Q-I schema通过或“官方”标签当完整数值资格。

## 已有事实与审阅范围
以0081645116664386f76f2bfa2ef428bcd74e846e为只读基线。DS-DATA-01有26atlas、33条引用，尚无该活动的正式split。旧F3数值配方和32例保留，只按真实可兼容范围复用。详细差异见REVIEW_ZH.md。

## P0 范围和共享入口（不重建大型平台）
1. 启动核实本地HEAD/远端和原始数据根；保护.vscode与其他未提交文件。建立新集成/各族worktree。
2. 记录用户实际采纳、新活动资源与到期。旧goal和旧预算不复活；本任务书本身不是已签署授权。
3. 取消旧学习队列依赖，历史权重和日志保留不加载；不停止不属本活动的作业。
4. 复用已有GenCase/GPU/BI4/HDF5流水线，只修必要公共语义：solver维度、typed IDs/Zone、原生排除、有限壁面、Q-N定义与scope gate。
5. 将最新状态/精简receipt提交进Git；原始大数据保持外部归档。不要像旧resume目录一样连关键状态也全部ignored。
6. 第一轮只修阻塞真实生产的共用功能；家族研究同步开始，不用把一个新controller写完作为所有工作的唯一入口。

## P1 七族母例/机制
七个family owner分别按families/Fn.md推进，不等待其他家族通过。每族明确两个机制背景与至少一个非平凡横向机制、适用物理模型、已知控制与必要输出。
官方原样母例若已有原始结果和等价输入直接复用；若过大或2D只用于相应校准，不改文件名假装3D。完整包/实际版本优先，文献与wiki用于理解而非覆盖本地执行值。
母例输入预检必须检查GenCase实际粒子数、维度、物理尺寸、初始质量、边界层、运动/驱动文件覆盖、潜在ghost/周期重复。按对象与特征尺度选dp，不采用跨家族统一米制dp。
软目标：主生产完整流体状态约1万–20万粒子，个别机制可合理更大；Gold参考另设更高规模。不是科学硬限，超过目标需有本族机制解析与实测成本依据。超过200万粒子先协调记录成本，超过500万不默认启动；优先缩短诊断窗口、复用旧大算例或选尺寸可控的新物理问题，不把粗欠解析数据塞入核心。

## P2 代表性时空资格
每族2背景×3分辨率是默认矩阵（已等价旧结果可复用）。背景至少涵盖平稳/低强度与较强相互作用，或两个不同机制。三档的连续初态与有效物理壁面可比，检查质量与位置取整误差。
积分时间误差与保存频率独立研究，最关键背景各一项起步；目标事件窗覆盖完整机制。不能以“资源上限允许跑0.6秒”决定科学时域。
质量观测使用QUALITY_AND_SCHEMA_ZH.md和本族卡；F6必须有刚体状态，F2/F3/F7必须有真实控制/运动信息，F5必须有传播至目标的阶段，F4有限/开放分开。
第三方/解析观测用于能匹配的锚点，作为独立Q-E轴。缺逐粒子实验真值不否定合格Q-N。
若失败：区分输入、转换、审计、物理/数值、资源；先复用原始数据取证。每类根因最多两次有假设修复，再切合法母例/更简单可解析背景。通过另一背景即继续相应scope，不为等全家族而停。

## P3 参数范围与预注册split
通过参考模板后确定两条主要物理轴和对应可行域，以有约束空间填充而非全笛卡尔积生成候选。
在端点与至少一个未用于调配方的内部点检查参考适用性。几何/控制holdout只能超出训练支持，不能超出已验证求解器可用域；新几何需自己的数值证据，不根据模型表现挑难例。
定义48例的有意义分配，先完成8/24子批。不强制每族相同数值参数，统一的是字段、单位、身份、任务含义和质量等级。

## P4 条件式批量生产
scope生产函数只需要：当前schema/inputs/geometry有效、Q-I与Q-N范围有效、父组split无泄漏、case位于范围、资源许可。
严禁读取模型B2 gate、要求全七族canary无失败、要求新配方计数>0才允许复用既有有效配方、或要求全部Q-E/T2通过。
先8例完整运行、转换、标签与抽样QA；若无新系统性故障继续24/48。所有候选和失败进入manifest；不得只公布通过case而隐藏失败采样分布。全量质量检查，数值Gold按风险和预注册分层抽查，不为全部生产case三档复制成本。
每族配方变化生成新version，旧/新case可分别发布但不能混称同一范围；不在生产时悄悄改边界/CFL/黏性。

## P5 数据标签与无模型接口
按原生数值身份生成来源/去向/first-passage/residence等实际sidecar；关键字段见共享schema。2D、open、adaptive分别视图，不能混进固定3D闭式score。
无模型evaluator只读取reference/候选轨迹文件；正确参考自比较、解析/人工错误注入、时间/身份/质量错误必须被检测。绝不加载模型权重或执行神经网络。
材料独立tracer只在确有价值且预算内最多12完整配置；不优先改GPU化、不重复全时域超时、不作为核心前置。合格数据先发布原生语义层。

## P6 独立数据复验与打包
各族独立审阅至少重读8个先行case的全时程并抽两个重建元数据/标签；全48做哈希、shape/finite/ID/mass/time账。
形成每族HDF5与可移动路径manifest、生成器、配方/任务卡、split、labels、真动画/关键帧、失败地图与资源模型。总索引分开统计视图和独立案例；旧32例是否与当前引用重复必须按源哈希+物理组核对。
检验中断恢复、不可变输入与原子产物提交、损坏拒绝、分块读取和磁盘峰值。许可证/第三方再分发需查资产级来源，不默认“用了开源求解器=所有实验数据相同许可”。无获准对象存储仍可交付本地可移动bundle；缺公共存储不能阻塞本地生产或冒充已上传。

## 完成、暂停与部分交付
阶段报告/测试数/哈希验证是支持材料，不是完成条件。
目标完整：七族各至少一份Q-N可生产scope、两类机制覆盖、真实独立case目标48且合法split/label/evaluator；每族未达到48如有明确物理可行域/重复性限制可报真实数量但总体标部分完成。
阶段性产品：七族每族8例/24例是有价值checkpoint，其他ready工作继续。某族失败不妨碍其他成品；最终若不是七族，不得把partial改名comprehensive。
负结论终止需要列出已执行模板/背景/修复和对应证据，并证明没有剩余ready任务；未实现功能、缺摘要报告、没模型、没有Q-E、不够GPU满载均不是负结论。
父预算/期限到达则提交partial_budget_or_deadline，不改变已取得的数据资格。

## 回归边界
运行本活动纯数据、生成、转换、标签和无模型evaluator回归。不得自动执行可能启动旧训练smoke、加载权重或模型forward的全库测试；共享几何工具若耦合学习模块，应提取为数据侧纯函数，不以重跑模型验证。
